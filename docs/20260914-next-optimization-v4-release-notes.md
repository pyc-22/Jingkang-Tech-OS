# 20260914-next-optimization-v4 发布说明

## 本版内容

- 房间卡片在派单超时或取消派单状态下直接提供“重新派单”和“取消派单”，弹窗创建不再依赖已停用的待处理面板。
- 技师接单后可从技师端开始服务，前台仍可代操作；两端复用同一服务开始时间、预计结束时间和加钟后时长。
- 结算时手工添加项目可选择钟类、15-360 分钟时长、可选房间及 1-4 位技师，并校验业绩比例合计为 100%。
- 后端在结算事务内为带归属信息的手工项目创建已完成服务单和参与者，关联订单行，并复用现有提成计算与报表链路。
- 无房手工服务可保留在订单详情、技师明细和经营查询中；Flyway V93 将 `service_session.room_id` 调整为可空。
- 前端静态资源缓存版本统一为 `20260914-next-optimization-v4`。

## 兼容性

- 原有三字段手工订单行请求继续按旧行为处理。
- 正常服务单结算、单技师流程及前台代开始服务保持不变。
- V93 只放宽房间字段约束，不改写已有服务数据。
