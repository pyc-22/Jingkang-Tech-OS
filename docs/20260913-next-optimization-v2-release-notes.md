# 20260913-next-optimization-v2 发布说明

## 发布结论

这是基于完整当前工作树的前后端综合修复版本。既有日报 Bug1/2/3/6、V87-V91、技师端 403、店长安排上钟、400/409 冲突处理和需求 1-7 均保留；本轮完成历史补单弹窗排版以及会员充值渠道统计修复。

## 前端变更

- 历史补单弹窗扩大工作区并按订单信息、项目卡片、技师业绩、金额汇总和支付方式分组。
- 日期与订单会员独立成行；每个项目独立显示项目/钟类、时长、房间、金额和删除操作。
- 技师业绩区域显示姓名、工号、状态和百分比分配，支付方式支持多行混合支付，底部汇总已分配与待分配金额。
- 金额合计、实收金额、提成绑定提示和底部操作按钮保持清晰对齐，并增加窄屏布局规则。
- 保留原有元素 ID、数据属性、项目增删、技师分配、金额计算、支付和补单提交逻辑。
- 静态资源缓存版本统一为 `20260913-next-optimization-v2`。

## 充值渠道统计变更

- 日报统一服务按 `wallet_transaction.transaction_type='RECHARGE'` 和支付方式聚合充值金额。
- `RECHARGE_REFUND` 调整流水按原充值支付渠道计入负向净额；赠送余额流水不进入外部渠道。
- 日报、运营支付渠道摘要和前端渠道明细共享订单净额、充值净额与总净额字段。
- 会员余额消费仍不计入外部现金流；现金流由外部订单净额与充值净额组成。
- 现有开卡、充值、续卡接口继续写入支付方式及名称快照，保持历史数据兼容。
