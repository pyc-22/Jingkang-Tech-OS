# 20260913-next-optimization-v1 发布说明

## 发布结论

这是基于完整当前工作树的前后端综合优化版本。既有日报 Bug1/2/3/6、V87-V91、技师端 403、店长安排上钟和 P0 400/409 冲突修复均保留；本轮主要完成前台和店长端历史补单、多技师派钟与结算展示。

## 前端变更

- 多技师批量派钟调用 `/service-sessions/clock-in-batch`，每位技师独立选择项目、钟类、数量、时长和床位。
- 前台下钟增加二次确认，显示技师、工号、房间、项目和已服务时长。
- 历史补单入口迁移到前台；补单复用下单表单，支持补单日期、项目提成、会员搜索、多技师分配、现金/微信/支付宝/余额/混合支付、退款和记录筛选。
- 店长手机端移除新建补单，仅保留补单记录；前端按 `HISTORICAL_ORDER_CREATE` 权限显示入口。
- 待付款房间卡片补充技师、工号、项目和多人摘要。
- 静态资源缓存版本统一为 `20260913-next-optimization-v1`。

## 后端兼容性

本版本不新增前端以外的业务接口改写；现有单技师派钟流程保持兼容。后端已完成的批量派钟、打卡门禁、历史补单权限和记录接口继续使用。新增数据库对象为追加式，既有订单默认不是历史补单。

## 已知边界

真实资源竞争仍可能按设计返回业务 409。部署前必须备份数据库、JAR、静态资源和外部配置；代码回滚不等于数据库迁移回滚。
