# 数据、备份与制品边界

## 权威数据

- PostgreSQL：订单、会员钱包、服务会话、权限、报表、审计等业务数据。
- `MASSAGE_EXPENSE_STORAGE_DIR`：报销凭证附件。
- 生产服务环境与秘密管理器：数据库密码、证书和签名配置。

数据库与附件必须外置持久化、按同一恢复点备份并定期恢复演练。附件目录不得放在 Maven `target/`、仓库或临时目录中。

## 历史制品

`deploy/releases/`、`deploy/package/`、根目录 JAR/ZIP、APK/AAB 和数据库备份可能用于追溯或恢复，但不是权威源码。本轮保留原位并由 `.gitignore` 分类；完成外部归档、校验哈希、确认保留期限和恢复责任人后才能清理。

## 运行与临时数据

`data/`、`services/*/data/`、日志、截图、视频帧、`.tmp-*`、`.artifacts/`、`target/`、`node_modules/`、Android `build/` 和 Gradle 缓存均不应提交。运行日志应轮转并按运维策略保留。

## 敏感信息

数据库备份、附件、浏览器配置、令牌、证书、keystore 和真实 `.env` 都可能包含敏感信息。不得上传到公共制品库、问题追踪器或第三方分析服务。示例配置只能使用占位符。

## 清理门槛

删除历史制品前应：

1. 记录文件清单、大小和 SHA-256。
2. 完成至少两份独立存储，其中一份不在生产主机。
3. 验证数据库可恢复、附件可读取、发布包可解压。
4. 获得业务与运维保留期限确认。
5. 只删除明确列入清单的路径，不使用仓库级批量清理。
